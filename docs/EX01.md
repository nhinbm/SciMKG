# Ex01: chi phí một bài học

Một bài học đi từ văn bản đến đồ thị tốn bao nhiêu lời gọi, token và tiền.
Ex01 không chấm chất lượng; xem Ex02.

## Kết quả

Bài `nervous-system` (14 đoạn, 27 ảnh), `gpt-6-luna`, run W&B `7b20992d11ea`.

| Số đo | Giá trị |
|---|---:|
| Lời gọi | 335, không lỗi |
| Token vào CLI (đã lưu sẵn) | 4.325.932 (2.779.392) |
| Token ra | 14.909 |
| Token vào kiểu API | 194.849, khoảng 4,5% số CLI |
| Tiền một bài | 0,027 USD (kiểu API) đến 0,19 USD (CLI) |
| Đầu ra | 104 khái niệm, 744 bộ ba, 1.097 câu RDF, 104 tệp âm thanh |

- V, giải thích và căn chỉnh ảnh chiếm khoảng 91% token CLI.
- Khoảng 96% token vào CLI là ngữ cảnh cố định của Codex: lượt chỉ có chữ luôn dư 12.339 đến 12.350 token so với prompt và schema.
  Vì vậy số CLI là cận trên, số kiểu API là cận dưới.

## Thiết lập

- Mô hình `gpt-6-luna`, effort `low`, qua Codex CLI đăng nhập ChatGPT (thuê bao, không phải API).
- Prompt và luật của mã tác giả: 5 vòng kiểm chứng, ngưỡng 0,7.
- Các bước: E (một lời gọi mỗi đoạn), V (hai lời gọi mỗi vòng), I (không gọi), A (ConceptNet 5.7.0, bản dump ghim SHA-256), ảnh (ba lời gọi mỗi ảnh), giải thích (Wikipedia tiếng Trung khi có), âm thanh (`say`, chạy cục bộ), RDF.
- Video chưa chạy vì không có video gốc.
- Tiền kiểu API: đếm prompt và schema bằng `o200k_base`, cộng token ảnh ước lượng theo quy tắc high detail, không tính cache; giá lưu theo ngày chạy trong `pricing/`.

## Cách chạy

```bash
for s in E V A all; do
  .venv-ex01/bin/python scripts/experiments/ex-01/run.py run --model gpt-6-luna --until "$s" || break
  [ "$s" != "all" ] && sleep 3600
done
.venv-ex01/bin/python scripts/experiments/ex-01/analyze.py   # chỉ đọc file đã lưu
```

- `--until` dừng sau một bước; chạy lại cùng lệnh sẽ tiếp tục từ cache.
- Hết hạn mức thì thoát với mã 75; tạo file `STOP` trong thư mục run để dừng trước lời gọi tiếp theo.
